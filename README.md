# Overmask - Proyecto Final Computacion Grafica

> Ambiente virtual interactivo basado en *The Legend of Zelda: Majora's Mask* con elementos prehispánicos y de lucha libre mexicana.

## 🎮 Controles

### Movimiento del Personaje
| Tecla | Acción |
|-------|--------|
| `W` `A` `S` `D` | Mover a Deku Link |
| `Mouse` | Rotar cámara |
| `Scroll` | Zoom in/out |

### Iluminación
| Tecla | Acción |
|-------|--------|
| `Space` | Encender/apagar linterna de Navi |

### Interacciones
| Tecla | Acción |
|-------|--------|
| `Click Izquierdo` | Disparar nuez Deku |
| `Q` | Navi da una vuelta alrededor de Link |

### Sistema
| Tecla | Acción |
|-------|--------|
| `ESC` | Salir del programa |
